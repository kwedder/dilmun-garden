The app runs one small model on this phone's processor. It never goes online, so the model comes in as a file:

1. Download LFM2-1.2B in the GGUF format (the plain Q4_K_M file, about 0.7 GB). Other GGUF models work too.

2. Tap Import model file and pick the .gguf file from your downloads. The app checks it, keeps a copy, and records its fingerprint on everything it writes.

Diagnostics

    Sources

    Text files the agent may read. The workspace map records what each one holds, so a run on a file that changed is refused until you rescan.

    Bulk extract

    Keep the app open: the screen stays on while a run is going. Each source gets its own directive when its turn comes, and its own signed result.

      Without a model

      The pattern agent reads lines written as entity | attribute | value, for example aspirin | treats | fever. Each one is quoted exactly from the file, and the arbiters keep it only if the attribute is in the schema:

      When a model is loaded on the Ask tab, Extract uses it instead: it reads each file a passage at a time and proposes facts with quotes, and the arbiters keep only the facts whose quote is really in the file.
